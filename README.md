# Want to stay updated with the exchange rate and a specific stock? #

This project streams real-time stock data, processes it using Apache Kafka and Apache Spark, and displays the processed data in real time. It includes integration with the Yahoo Finance API to fetch stock data and ExchangeRate-API to convert prices to the desired currency.

## Features
- [x] Real-time stock price tracking (via Yahoo Finance API)

- [x] Conversion of stock price to a specified currency (via ExchangeRate-API)

- [x] Integration with Apache Kafka for message streaming

- [x] Real-time data processing and output with Apache Spark

## Requirements
- [x] To run this project, you will need:

- [x] Apache Kafka (for managing the real-time stream of stock data)

- [x] Apache Spark (for processing the streaming data)

- [x] Python 3.x (with necessary libraries installed)

- [x] Yahoo Finance API (for fetching stock data)

- [x] ExchangeRate-API (for currency conversion)
